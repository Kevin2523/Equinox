# Prototipo Equinox

Prototipo responsive del centro de control de Equinox, creado con HTML, CSS y JavaScript puro.

## Abrir localmente

Abre `dist/index.html` en cualquier navegador moderno. No necesita instalación ni dependencias.

## Archivos

- `dist/index.html`: estructura y contenido.
- `dist/styles.css`: diseño completo, responsive y animaciones.
- `dist/script.js`: modal, navegación, búsqueda, tareas y notificaciones.
