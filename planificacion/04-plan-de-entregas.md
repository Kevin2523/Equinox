# Plan de entregas

## Fase 0: Alineación y diseño

- Validar alcance, roles, casos de uso y reglas de negocio de esta carpeta.
- Cerrar flujo visual de las 12 pantallas y estados vacíos/carga/error.
- Definir proveedor de almacenamiento de archivos y correo transaccional.

## Fase 1: Fundaciones

- Configuración de PostgreSQL, Prisma, migraciones y datos iniciales.
- Registro, inicio de sesión, autorización por organización y perfil.
- Estructura Angular, sistema visual y consumo base de API.

## Fase 2: Operación del freelancer

- CRUD de clientes y proyectos.
- Tareas, hitos, comentarios internos, archivos y registro de actividad.
- Dashboard, búsqueda, filtros y estados de interfaz.

## Fase 3: Relación con el cliente

- Entregables visibles, emisión y revocación de token.
- Portal de cliente, feedback y previsualización de marca.
- Facturación y seguimiento de vencimientos.

## Fase 4: Calidad y salida

- Pruebas de autorización, reglas del portal y flujos principales.
- Pruebas de usabilidad con freelancers panameños.
- Observabilidad, respaldo de datos, manual breve y despliegue.

## Definición de terminado

- El flujo está probado en interfaz, API y base de datos.
- Maneja éxito, carga, vacío y error con texto claro en español.
- Respeta autorización, validación y reglas de negocio.
- Tiene revisión de diseño responsive y no contiene datos o secretos reales.
