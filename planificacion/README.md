# Planificación de Equinox

## Diagramas

Abre directamente [casos-de-uso.drawio](diagramas/casos-de-uso.drawio) desde **app.diagrams.net** con `Archivo → Abrir desde dispositivo`; es XML nativo, editable y no requiere conversión.

Todos los archivos `.drawio` son XML nativo de diagrams.net y se pueden editar directamente. Para abrirlos, usa `Archivo → Abrir desde dispositivo` en app.diagrams.net.

Los diagramas incluidos son: casos de uso, componentes, secuencias del portal, modelo de dominio y ciclo de vida del proyecto.
